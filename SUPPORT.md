# Support

For usage questions, reproducible defects, and feature proposals, open an issue:

https://github.com/Luizinfo/IdentityModel.AspNetCore.AccessTokenValidation/issues

Include the package version, target framework, minimal reproduction, expected behavior, and actual behavior. For vulnerabilities, use the private Security Advisories channel described at https://github.com/Luizinfo/IdentityModel.AspNetCore.AccessTokenValidation/blob/main/SECURITY.md

Support is community-maintained and has no guaranteed response-time SLA.
