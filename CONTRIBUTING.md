# Contributing

Open an issue at https://github.com/Luizinfo/IdentityModel.AspNetCore.AccessTokenValidation/issues before substantial work. Keep changes focused, preserve compatibility unless a breaking change is agreed, add or update tests, and ensure restore, Release build, tests, and package creation succeed before submitting a pull request.

Security reports must follow https://github.com/Luizinfo/IdentityModel.AspNetCore.AccessTokenValidation/blob/main/SECURITY.md rather than a public issue.
